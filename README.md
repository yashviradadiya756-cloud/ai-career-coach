# AI Career Coach Platform

AI-powered career guidance platform built using MERN stack.

## Features

- User Authentication (JWT)
- Resume Upload & Analysis
- AI Resume Analyzer
- Skill Gap Analysis
- Career Roadmap
- AI Mock Interview
- Learning Progress Tracking
- Achievement System
- Payment Integration

## Tech Stack

Frontend:
- React.js
- Vite
- Tailwind CSS

Backend:
- Node.js
- Express.js

Database:
- MongoDB

AI:
- Gemini API
